# ReaderBook — LitRes Browser для PocketBook 617

Приложение и файлы онлайн-обновления публикуются в [Releases](https://github.com/AnDmVar/ReaderBook/releases).

Для первой установки скачайте `litres.bin`, переименуйте его в `litres.app` и скопируйте в папку `applications` на устройстве. Начиная с v0.6.8, следующие версии устанавливаются через «Настройки → Проверить обновления». Прошивка не изменяется.

В открытой книге ↑/↓ сдвигают текст на строку; клавиши листания — на экран с перекрытием в одну строку. Поведение ←/→ настраивается. Короткое OK активирует элемент, долгое OK открывает меню приложения.

Обновлятор проверяет подпись Ed25519, размер, SHA-256 и формат ARM-приложения. Предыдущая версия сохраняется для ручного отката. GitHub-токен на устройстве не нужен.

v0.6.8 прошла ARM-сборку и изолированные проверки управления, подписи, установки и отката. Проверка на физической PB617 после установки ещё требуется.
