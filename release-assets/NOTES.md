Управление открытой книгой: ↑/↓ — одна строка; клавиши листания — экран с перекрытием в строку. Поведение ←/→ настраивается. Короткое OK активирует элемент, долгое OK открывает меню приложения.

Добавлены подписанные онлайн-обновления и ручной откат. Для первой установки скачайте litres.bin, переименуйте в litres.app и скопируйте в applications на PocketBook. Начиная с этой сборки v0.6.8, следующие версии можно получать через «Настройки → Проверить обновления».

Проверено: ARM-сборка, модель читалки в Chromium 73, быстрые нажатия, подпись/размер/SHA-256, атомарная установка и откат. Полную работу на физической PB617 ещё нужно проверить. Прошивка не изменяется.
