# v0.6.16

Меню открытой книги: «Мои книги ЛитРес», «Сохранённые книги», «Главное меню приложения». Возврат в ЛитРес больше не подменяется сохранёнными книгами по флагу Wi-Fi. Локальная позиция сохраняется перед выходом, синхронизация запускается при доступной сети.

В списке сохранённых книг стрелки переводят фокус между списком и кнопками. Поддержаны Return и физический Enter; левая клавиша листания возвращает в «Мои книги» ЛитРес.

При повороте InkView обновляются кэшированные границы QScreen через экспортированный API QPA Qt 5.12. Это устраняет старую портретную область отсечения. Версия Qt закреплена в проекте; при отсутствии функции приложение пишет hook=0 в журнал. Размер окна и области текста также пересчитывается. Позиция чтения сохраняется.

Значок меню устанавливается как 24-битный BMP; view.json использует объект path по образцу производителя. Другие пункты меню и пользовательские данные сохраняются. Для обновления кэша рабочего стола после USB-установки нужен перезапуск устройства.

Проверки: ARM EABI5 сборка с локальным builder; Qt-тест границ экрана, RGB24 BMP и конфигурации; управление списком стрелками/Enter/Back/Home; интеграционные сценарии поворота и выхода на синтетической книге без реальной записи прогресса. Отображение после поворота и значок требуют визуальной проверки на PB617 после отключения USB.
